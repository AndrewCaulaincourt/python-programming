# Лабораторная работа №2: Сумма двух чисел (Two Sum)

## Описание задачи

Написать функцию `add`, которая принимает два аргумента:

- `nums` — массив (список) целых чисел;
- `target` — целевое целое число.

Функция должна возвращать индексы двух элементов массива `nums`, сумма которых равна `target`.

### Ограничения и условия:

1. Каждая входная комбинация имеет ровно одно решение или не имеет решений вовсе.
2. Нельзя использовать один и тот же элемент массива дважды.
3. Порядок возвращаемых индексов не имеет значения.

---

## Описание алгоритма и сложность

Для решения задачи используется подходы с **хэш-таблицей (словарём в Python)**:

1. Мы проходим по массиву `nums` с помощью `enumerate`, получая одновременно индекс `i` и значение `num`.
2. Для каждого числа вычисляется разность: `diff = target - num`.
3. Мы проверяем, есть ли `diff` в нашем словаре `seen`:
   - Если **есть**, значит, парный элемент уже встречался ранее. Мы возвращаем список из двух индексов: `[seen[diff], i]`.
   - Если **нет**, сохраняем текущее число и его индекс в словарь: `seen[num] = i`.

### Сложность алгоритма:

- **Временная сложность:** $O(n)$ — поиск в словаре выполняется за константное время $O(1)$, поэтому мы проходим по массиву всего один раз.
- **Пространственная сложность:** $O(n)$ — в худшем случае словарь `seen` будет хранить $n$ элементов.

## Тестирование

Для проверки корректности работы функции используется встроенный модуль `unittest`.

Тестовые сценарии:

1. **Тест 1:** `nums = [2, 7, 11, 15]`, `target = 9` $\rightarrow$ Ожидаемый результат: `[0, 1]`
2. **Тест 2:** `nums = [3, 2, 4]`, `target = 6` $\rightarrow$ Ожидаемый результат: `[1, 2]`
3. **Тест 3:** `nums = [3, 3]`, `target = 6` $\rightarrow$ Ожидаемый результат: `[0, 1]`
